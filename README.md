# 객실 공지사항 오프라인 뷰어

회사에서 내려받은 PDF를 GitHub 저장소의 카테고리별 폴더에 원래 파일명 그대로 올려두면, 앱이 자동으로 읽어서 분류하고 오프라인 저장까지 해주는 PWA(설치형 웹앱)야. 로그인은 팀 공통 아이디/비밀번호로 간단하게 막아뒀어.

## 1. 로그인

- 아이디: `PTACC`
- 비밀번호: `ptacc1!`

부서 전체가 이 값을 공유해서 써. 바꾸고 싶으면 `app.js` 맨 위쪽의 `LOGIN_ID`, `LOGIN_PW` 값만 고쳐서 Commit하면 돼. (참고: 이건 개인정보 없이 "아무나 못 들어오게"만 막는 가벼운 잠금이야 — 코드를 열어보면 비밀번호가 그대로 보이고, PDF 원본 주소도 직접 접근은 막을 수 없어. 진짜 보안이 필요한 자료는 이 방식에 올리지 않는 게 좋아.)

## 2. 폴더 구조

`notices/` 폴더 안에 카테고리별 폴더가 있어. PDF를 원래 파일명 그대로 해당 폴더에 넣으면 돼.

```
notices/
├── Safety&Security/
├── Service/
├── General/
├── Catering/
├── Schedule/
├── Manual/
└── Station Information/
```

- 파일명은 안 바꿔도 돼 — 그 이름이 그대로 화면 제목으로 나와.
- 카테고리는 폴더 이름으로 정해져. 새 카테고리가 필요하면 `notices/` 아래에 폴더를 하나 더 만들면 자동 인식돼.
- 폴더 없이 `notices/` 바로 아래에 PDF를 올리면 "미분류"로 분류돼.
- 내용이 완전히 같은 파일이 실수로 여러 번 올라가도 한 번만 표시돼(중복 자동 제거).

## 3. 처음 배포 (GitHub Pages)

1. **공개(Public) 저장소**를 하나 만들고 이 폴더 전체를 올린다. (공개 저장소여야 앱이 GitHub API로 목록을 읽어올 수 있어.)
   - 저장소 페이지에서 Add file → Upload files로, 압축 푼 폴더 **안의 내용물**을 전체 선택해서 드래그 → Commit.
   - 폴더 구조가 그대로 유지되도록 드래그 앤 드롭으로 올려야 해 (파일 선택 버튼으로는 폴더 구조가 깨짐).
2. 저장소 **Settings → Pages**로 이동해서 배포 브랜치를 `main`, 폴더를 `/ (root)`로 지정하고 저장.
3. 1분 정도 지나면 `https://사용자명.github.io/저장소명/` 형태의 주소가 생겨. 그 주소로 접속해서 로그인하면 돼.
4. 스마트폰/태블릿에서 "홈 화면에 추가"를 하면 아이콘으로 바로 실행할 수 있어.

## 4. PDF 올리는 법

카테고리 폴더 주소로 바로 들어가서 업로드하면 편해:

```
https://github.com/사용자명/저장소명/upload/main/notices/카테고리명
```

(`Safety&Security`처럼 `&`가 들어간 이름은 주소에 `%26`으로 써야 해: `notices/Safety%26Security`)

## 5. 오프라인 사용 흐름

- 인터넷이 될 때 앱을 열면 폴더 전체 목록이 자동으로 갱신돼.
- PDF는 기본적으로 "PDF 보기"를 한 번 눌러본 것만 오프라인 저장돼. 비행 전에 전부 미리 받아두고 싶으면 **설정 → 전체 PDF 내려받기**를 눌러줘.
- 아이폰 사파리는 오프라인 저장 용량이 약 50MB로 제한되고, **일주일 동안 앱을 안 열면 저장 내용이 자동으로 지워질 수 있어** — 비행 며칠 전에 한 번 열어서 동기화하는 습관을 들이면 좋아. 안드로이드 크롬은 이런 제약이 훨씬 느슨해.

## 6. 코드를 고칠 때마다 꼭 할 일

`sw.js` 파일 안의 `SHELL_CACHE` 값(`cn-shell-v1`)을 숫자를 하나씩 올려서(`v2`, `v3`...) 같이 Commit해야, 다음에 접속했을 때 새 코드가 확실히 반영돼. 이걸 안 하면 예전 캐시가 남아서 수정사항이 안 보일 수 있어.

## 7. 저장소 용량

- 파일 하나당 웹 업로드는 25MB까지, 저장소 전체는 1GB를 권장 상한으로 잡고 있어.
- 1년 정도 부서 전체가 올려도 보통은 여유가 있는 편이지만, 저장소 메인 화면의 **Insights** 탭에서 가끔 용량을 확인해두면 좋아.
